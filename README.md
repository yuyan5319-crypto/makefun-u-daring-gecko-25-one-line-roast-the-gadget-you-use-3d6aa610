My entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): one original line roasting a gadget I use every day — my laptop.

> My laptop fan stays silent through whole movies, then screams like a jet engine the second I open a spreadsheet — Excel is apparently the most demanding game I own.

## Run it

```sh
node main.ts
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is 164 characters, a single line, within the 200-character limit.
