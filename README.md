My entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): one original line roasting a gadget I use every day — my wireless earbuds.

> My wireless earbuds last four hours on the couch and four minutes outside — fresh air must be their natural predator.

## Run it

```sh
node main.ts
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is 117 characters, a single line, within the 200-character limit.
